# Note per App Review

GestOre Lavoro e un archivio personale local-first per ore di lavoro, ferie, cedolini e stime stipendio.

## Accesso

La build sottoposta non richiede registrazione, login o account demo. Al primo avvio appare automaticamente una configurazione di tre passaggi. Il revisore puo completarla con dati sintetici e usare subito tutte le funzioni.

## Dati e rete

I dati restano nel contenitore privato dell'app. Non e configurato alcun endpoint API e le funzioni principali operano senza connessione. Profilo > Dati e backup permette di esportare o ripristinare una copia scelta dall'utente.

## Permessi

- Fotocamera: Stipendio > Archivio cedolini > Aggiungi > Scatta foto.
- Libreria foto: stesso percorso, scegliendo Galleria.
- Notifiche: promemoria locali opzionali attivabili nelle impostazioni.

## Funzioni da verificare

- toccare la card Home per inserire o modificare una giornata;
- aprire Calendario, Statistiche, Ferie e Stipendio dalla barra inferiore;
- esportare report PDF e backup attraverso il foglio di condivisione iOS;
- aprire una foto cedolino o un'anteprima PDF per usare lo zoom dedicato.

Il calcolatore dello stipendio produce solo stime informative e non esegue pagamenti, investimenti o consulenza fiscale.
