# Security policy

Do not open a public issue containing passwords, recovery codes, database files, backups, payslip photographs or personal work data.

For a reproducible bug, share only the GestOre version, device/browser version, expected behavior and minimal steps using synthetic data. Before a commercial App Store release, replace the public issue-only flow with a verified private security contact.

The public hosted deployment must use `GESTORE_DEPLOYMENT_MODE=public`, HTTPS, encrypted backups, individual administrator access and monitored retention. The Umbrel package remains a private self-hosted deployment.
